## What is the Data Management Pipeline?

The Data Management Pipeline lets you visually build data flows using nodes and connections on a canvas. You can fetch, transform, validate, and route data between nodes.

## Key Concepts

- Canvas: The workspace where you place and connect nodes.
- Nodes: Functional blocks (data-source, code, transform, buffer, console, data-sink, group).
- Connections: Links between node ports that represent data flow.
