## Canvas Basics

- Drag nodes to position them.
- Use the zoom controls to change scale; pan to move the view.

## Node Types

- Data Source: Fetch or stream data.
- Code: Custom logic in JavaScript/TypeScript.
- Transform: Built-in transformations and filters.
- Buffer: Batch and queue records.
- Console: Display records for debugging.
- Data Sink: Persist or forward records.
- Group: Organize sub-flows.
