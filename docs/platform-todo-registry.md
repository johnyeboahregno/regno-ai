## How to keep this in sync

This file is the source of truth. The `/admin/todos` dashboard reads
from a Mongo collection (`platform_todos`) which is seeded from this
markdown via `scripts/seed-platform-todos.cjs`.

Workflow:
1. Edit this file when adding / re-prioritising work
2. Run `node scripts/seed-platform-todos.cjs --apply` to sync to Mongo
3. The admin dashboard reads from Mongo and reflects state immediately

Or, conversely, ticks made in the dashboard can be exported back via
`scripts/seed-platform-todos.cjs --export` to update this file.
