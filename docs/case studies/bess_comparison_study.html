Sand Mine vs Data Center - Identical Hardware, Different Use Cases

ITX Z&T Ranch, Texas, USA

Executive Summary

This document compares the deployment of an identical Battery Energy Storage System (BESS) configuration across two distinct applications at the ITX Z&T Ranch location in Texas. Both installations utilize 40 Sungrow ST2236UX battery units (89.44 MWh) paired with 5 Sungrow SC4000UD-MV inverters (20 MW) in a dual-inverter topology.

Key Finding

The same BESS hardware delivers fundamentally different value propositions based on the host facility's load profile. The sand mine application creates a merchant storage asset focused on ERCOT market revenue, while the data center application replaces traditional UPS infrastructure while generating ancillary income. Both are financially viable, but with different risk/reward profiles.

Sand Mine Load Profile

Highly variable load with distinct operational periods:

  • Day Shift (6 AM - 6 PM): 300-420 kW (crushers, conveyors, processing)
  • Night/Weekend: 50-100 kW (lighting, pumps, security)
  • Seasonal Variation: Higher in construction season (Mar-Nov)
  • Equipment Cycling: Large motor starts create brief spikes
Sizing Implication

BESS is 48x larger than peak load. The system could power 48 identical sand mines simultaneously. This is a pure merchant storage asset that happens to be co-located with a sand mine.

Data Center Load Profile

Highly stable, continuous load with minimal variation:

  • IT Load: 10 MW constant (servers, storage, network)
  • Cooling: 3-4 MW (varies with ambient temperature)
  • Support Systems: 0.5-1 MW (lighting, security, offices)
  • PUE: 1.40 (total/IT ratio)
Sizing Implication

BESS provides 6.4 hours backup at full load - ideal for UPS replacement. The system is right-sized for both backup power and grid services.

Suitability Assessment

When to Choose Each Application Model

Sand Mine Model (Merchant Storage)

Best suited when:

  • Host facility has low, non-critical load
  • Primary goal is grid services revenue
  • Investor has appetite for market risk
  • Site has excellent grid interconnection
  • Low land cost / available space
  • Utility favorable to behind-the-meter storage

Key success factors:

  • ERCOT market access and understanding
  • Sophisticated energy trading capability
  • Tolerance for revenue volatility
Data Center Model (Infrastructure + Revenue)

Best suited when:

  • Host facility has high, critical load
  • Existing UPS systems need replacement
  • High 4CP exposure in ERCOT
  • 99.999% uptime requirement
  • Capital available for premium solution
  • Long-term facility ownership planned

Key success factors:

  • Integration with facility electrical systems
  • Operational excellence and monitoring
  • Grid services as supplementary income

Conclusion

Sand Mine Verdict

The sand mine application represents a pure merchant storage investment. The host facility is largely irrelevant - any location with grid access would work equally well. Returns depend almost entirely on ERCOT market performance.

Investment Grade B+ (Speculative)
Risk/Reward Higher risk, higher potential upside
Recommendation Proceed with experienced energy trader
Data Center Verdict

The data center application represents a strategic infrastructure investment with bonus revenue generation. Even with zero grid services revenue, the UPS replacement and 4CP savings justify the investment.

Investment Grade A (Core Infrastructure)
Risk/Reward Lower risk, stable returns + upside
Recommendation Strongly recommended for immediate development
Final Note

Both applications are financially viable with the same hardware. The choice depends on the investor's risk appetite, existing infrastructure, and strategic priorities. For pure financial returns with market expertise, the merchant model works. For critical infrastructure with revenue bonus, the data center model is superior. The hardware is agnostic - the value creation strategy makes the difference.
