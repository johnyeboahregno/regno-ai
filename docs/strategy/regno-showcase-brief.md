## Technical Differentiators (for reference)

### Cortex Flow Engine
- 10 execution frameworks (Claude, OpenAI, Gemini, Llama, Perplexity, LangGraph, Multi-Agent, Debate, Pipeline, Hybrid Router)
- Multi-phase architecture with intelligent context chaining via ContextBuilder
- Cost ceiling loop control: budget per execution, 70% info / 95% final iteration
- Crash recovery with phase-level MongoDB persistence
- Depth filtering: phases conditionally included based on analysis depth
- 50+ built-in tools, all enabled by default (LLM decides usage)
- MCP integration: 10,000+ community servers, bidirectional (client + server)

### Wisdom System
- Five input sources: self-annotation, QualityAuditor (3-layer), /apple evaluation, WisdomSynthesizer, showcase worker
- Hybrid retrieval: MongoDB text + Qdrant vectors, five-pronged merge
- Memory categories (priority): wisdom > patterns > errors > schema_cache > facts > preferences
- Domain tagging for filtered retrieval
- Shared memories (agentSlug: null) injected into ALL executions
- Confirmation tracking, usefulness rating, near-duplicate detection (>0.92), conflict detection
- Auto-prune: stale >90 days + low confirmation removed
- Cold start: 18 seed principles via `seed-quality-principles.cjs`
- Quality trajectory: baseline ~60 → 85+ without retraining

### Anti-Hallucination (7 layers)
1. DataSourceQueryBridge — queries real data, not LLM training knowledge
2. Synthesis prompt — "PRIORITIZE Live Data Query Results"
3. BSON normalisation — `normalizeBsonValue()` prevents data corruption
4. Cross-validation tables — reports prove their own numerical accuracy
5. PythonExec enforcement — statistics computed before document generation
6. Tool precision tracking — low precision stored as error memories
7. Multi-agent debate — advocate/critic/judge catches assumptions
8. Wisdom protocol — operational knowledge replaces guessing

### Speed Architecture
- Subagent system: 3-5 child agents, model-appropriate (Haiku 10x cheaper)
- Cost ceiling as speed control (not iteration-limited)
- Sliding window iterations: `{ initial, increment, max }`
- Phase-level parallelism for independent phases
- Domain aesthetic selection via Haiku (~$0.001/call)
- Canvas type selection: 19 types, LLM-selected

### Cost Intelligence
- Per-execution cost ceiling with real-time tracking
- Model tiering: Haiku $0.001 / Sonnet $0.01-0.05 / Opus $0.10+
- `estimateCost(response, model)` per-call tracking
- `token_progress` SSE events with live budget visibility
- Self-hosted Llama: 18x cheaper, break-even 0.3 months, ROI 4-6 months

### CORTEX Brain
- 1,080+ patterns across 83 domains in CortexRegistry
- 20 complete execution scenarios
- 27 project types for goal detection
- Volume-aware data strategy (tiny → massive)
- Self-evolving: detects knowledge gaps, generates new patterns
- User context graph (Neo4j) for personalisation

### Deployment
- Cloud: Vercel + MongoDB Atlas, 5 env vars, 10 min
- Self-hosted: Docker + Caddy, Redis, MongoDB, horizontal scaling
- Air-gapped: Llama + local stack, zero external calls
- Hybrid: sensitive local (Llama), frontier cloud (Claude/OpenAI)
