The problem every AI platform has

When an AI does something — answers a question, approves a transaction, sends a report — three things happen that nobody can see:

  • What information did it look at? Could include private customer data, stale records, a poisoned document.
  • What did it decide, and why? Probabilistic. Same input ≠ same output.
  • Who is responsible if it goes wrong? The user? The model? The platform?

Most AI products today answer all three with a shrug. "The model decided." "Sorry, we don't keep that." "Check the chat history." That's fine for a chatbot — it's a deal-breaker the moment a regulator, an auditor, or a customer's lawyer walks in.

What we built

A "black box flight recorder" for every AI decision, plus the wiring around it so the recorder is impossible to silently tamper with.

WS1
Audit chain
Every meaningful event is written to a log that is cryptographically chained — each row signs the previous one. Change any past row and the math breaks.
WS1
Daily Merkle root
The whole day's log compresses to a single fingerprint we can publish. Hand it out today; prove next year nothing was edited in between.
WS2 / WS5
Execution traces
A full recording of every AI run — inputs, tools used, intermediate steps, outputs. Replayable byte-for-byte for deterministic runs; structurally comparable for the fuzzy LLM bits.
WS3
Assurance API
A standard way for any module (CMS, knowledge base, Cortex Flow…) to plug into the same audit + replay machinery. Build once, every module gets governance for free.
WS19
Trust manifest
A public URL — /.well-known/trust.json — that publishes what controls we have, what certifications, and what the substrate is doing right now (audited events, latest verified root). Customers can poll it.
UX
Admin dashboard
An ops view to watch the substrate live: verify the chain, replay any trace, list every TODO across the platform, see role/privilege assignments at a glance.
SEC2
Role & privilege catalogue
A single source of truth for who can do what inside the admin surface. One file. Bootstrap script for the first admin. No spreadsheet, no tribal knowledge.
Tracking
TODO registry
Every committed piece of governance work is on a public-internal list, tracked from inception to completion. The roadmap is just as auditable as the runtime.
Docs
Documentation provenance
The documentation is held to the same standard as the runtime: docs are never edited in place — a revision writes a new version and keeps the old one, recording who changed it, when, and why. The platform flags its own stale docs and can answer "what do we say about X, and where" with cited sources. Even the paperwork has an audit trail.
