Battery Management System Overview

The KymaGrid Battery Management System (BMS) is a software-defined energy control platform built on the Regno telemetry infrastructure that orchestrates industrial battery energy storage systems through a dual-inverter topology separating charging (OnGrid PCS) and discharging (OffGrid PCS) paths. The system features a sophisticated Model layer responsible for stateflow management, decision logic, and safety enforcement while generating real-time setpoints for power conversion equipment, combined with a Dashboard platform that serves as the supervisory "brain" providing fault tolerance orchestration, real-time data streaming to Regno databases, and remote monitoring capabilities—enabling hardware-independent deployment across diverse sites while handling demanding operational scenarios including overnight trickle charging at 10 kW continuous, inrush events up to 230 kW, and seamless transitions between grid-connected and fully islanded operation modes that have been proven to sustain real plant loads for extended periods without grid connection.

The Tricks

Key capabilities that make the KymaGrid BMS a sophisticated, field-proven energy management system:

🔌

Hardware-Independent Deployment

The communication layer was re-architected to decouple from physical hardware requirements. The Model can now run as a standalone service integrated into any site's software stack, making deployments faster, more repeatable, and hardware-agnostic across different battery chemistries and PCS configurations.

🔄

Independent OnGrid/OffGrid Operation

OnGrid and OffGrid PCS operate completely independently. When the generator is turned off, the OnGrid PCS enters standby while the OffGrid PCS continues discharging to the plant without interruption. This enables simultaneous charging and discharging, or complete grid isolation during outages.

⚡

230 kW Inrush Event Handling

The system handles occasional inrush events up to 230 kW while maintaining stability. Short power bursts (~0.06 kWh each) are absorbed without failure, demonstrating the system's ability to manage both steady operational loads and sudden high-demand transients.

🌙

Overnight Trickle Charging

Intelligent overnight charging at 10 kW continuous from ~18:00 to 09:30, maintaining battery SOC at optimal levels (68% by morning). This gentle charging approach extends battery life while ensuring full capacity for peak demand periods during daytime operations.

📱

Remote Access & Control

Full supervisory control established via Starlink connectivity for the Brain, battery, and PCS. Enables secure remote monitoring, deployment of software updates, and remote command issuance—reducing on-site intervention needs and enabling centralized management across multiple sites.

🛡

Fault Tolerance Orchestration

The Dashboard monitors subsystem health and automatically manages recovery procedures. It handles fault tolerance by coordinating interactions between core systems, battery, PCS, and Model to ensure safe and optimized operation even during unexpected conditions.

📊

Real-Time Setpoint Generation

The Model layer continuously generates real-time setpoints (charge/discharge commands) and propagates them to the PCS. This stateflow management ensures optimal power flow decisions based on current system state, load demands, and safety constraints.

🗄

Regno Data Streaming

All system data is collected and streamed into Regno databases for detailed diagnostics, historical analysis, and fault tracing. The INSIGHT platform provides visualization of system status, error diagnostics, and allows engineers to monitor or intervene as needed.

🏭

Proven Off-Grid Plant Operation

Successfully demonstrated fully off-grid operation at ZnT—plant ran for 2+ continuous hours powered solely by battery with no grid connection. The system sustained real plant loads (35-45 kW steady, 230 kW peaks) validating industrial-scale islanded operation.

🔧

PCS Frequency Stabilization Tuning

PCS firmware upgraded to allow fine-grained control over synchronization parameters. After tuning startup timing to accommodate generator frequency overshoot, the system achieved stable operation and successful battery charging from generator sources.

📦

Blackbox "Brain" Architecture

The control system runs on OnLogic hardware (the "Brain") containing the database and software stack with UPS backup. This self-contained unit eliminates external laptop dependencies and provides a scalable foundation for managing deployments across multiple sites.

🔀

Flexible Integration Topologies

KymaGrid supports multiple integration options: Parallel Integration (common DC/AC rails), Split Integration (separate charging/discharge AC rails), and HV Group Integration (DC groups to single PCS). This architectural flexibility adapts to diverse site requirements.

Integration Topologies

KymaGrid offers flexible integration architectures to match site requirements:

Topology DC Rail AC Rail Use Case
Parallel Integration Common DC Rail Common AC Rail Standard grid-tied applications
Split Integration Common DC Rail Separate Charge/Discharge Rails Independent OnGrid/OffGrid operation (ZnT)
HV Group Integration DC Groups to Single PCS All PCS in Parallel Large-scale multi-MW deployments

Z&T Deployment Configuration

The ZnT site uses Split Integration with a common DC rail for all BESS and PCS units, plus 2 separate AC rails (charging and discharge). This enables the "jump start" capability where BESS 101-104 and PCS-1 initialize with an external source, then PCS-1 generates AUX power for all remaining units.
