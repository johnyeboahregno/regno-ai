Battery Management System Overview

The Kyma Battery Management System (BMS) is a software-defined energy control platform that orchestrates industrial battery energy storage systems through a dual-inverter topology separating charging (OnGrid PCS) and discharging (OffGrid PCS) paths. The system features a sophisticated Model layer that manages state machine logic, decision arbitration, and safety enforcement while generating real-time setpoints for power conversion equipment, combined with a Dashboard platform providing supervisory control, fault tolerance orchestration, and remote monitoring capabilities—enabling hardware-independent deployment across diverse battery chemistries and inverter configurations while handling demanding operational scenarios including overnight trickle charging, inrush events up to 230 kW, and seamless transitions between grid-connected and islanded operation modes.

The Tricks

Key capabilities that differentiate the Kyma BMS from conventional battery management systems:

🔌

Hardware-Independent Deployment

Decoupled communication layer allows the same control software to operate across different battery chemistries, inverter brands, and PCS configurations without code changes.

🔄

Dual-Inverter Independence

OnGrid and OffGrid PCS operate independently, enabling simultaneous charging from grid while discharging to load, or complete grid isolation during outages.

⚡

230 kW Inrush Handling

Sophisticated state machine manages extreme inrush events up to 230 kW, automatically adjusting setpoints and coordinating PCS response in real-time.

🌙

Overnight Trickle Charging

Intelligent charging algorithms optimize overnight charge cycles at low C-rates, extending battery life while ensuring full capacity for peak demand periods.

📱

Remote Access & Control

Full supervisory control available remotely through the Dashboard platform, enabling parameter adjustment, fault diagnosis, and operational mode changes from anywhere.

🛡

Fault Tolerance Orchestration

Automatic failover between power sources (grid, battery, generator) with seamless transitions and coordinated safety enforcement across all subsystems.

📊

Real-Time Setpoint Generation

Model layer continuously computes optimal power setpoints based on current state, load demands, grid conditions, and battery health parameters.

🔀

Seamless Mode Transitions

Smooth switching between grid-connected, islanded, and hybrid operation modes without power interruption to critical loads.
