# Documentation Standard

> Non-negotiable base. Everything the system does or builds must be documented.

## What gets documented

- **Every module/API** — purpose, inputs/outputs, examples
- **Every artifact the agent builds** — what it is, why, and how it works
- **Every decision** — rationale, alternatives considered

## Format

- Markdown, one file per topic, under `docs/`
- Front matter: title, date, status
- Code examples are required for anything non-obvious

## Rules

- A change without docs is incomplete
- Docs live next to code (or in a linked `docs/` index)
