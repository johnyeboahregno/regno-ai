# Editing Subject Matter Experts

Subject Matter Experts are editable from `/app/agents`.

## Update an SMA

1. Open `/app/agents`.
2. Find the SMA in the **Subject Matter Experts** table.
3. Click **Edit**.
4. Change the name, description, focus tags, disciplines, or languages.
5. Save changes.

The built-in **Base Regno Architect** profile cannot be edited or deleted. Existing jobs keep their
recorded execution history, while new Architect jobs use the latest SMA configuration.
